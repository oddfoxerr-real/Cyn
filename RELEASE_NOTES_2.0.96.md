# CYN Windows 2.0.96 — Quiet Material Interface

CYN v2.0.96 simplifies the new **Riff / Material** Windows interface while retaining the original FxSound audio engine and all of its capabilities.

## Simpler Sound Studio
- A restrained graphite theme replaces overlapping cards, bright gradients, redundant labels, and oversized status panels.
- Sound Studio now emphasizes the current preset, real Windows output device, power, equalizer curve, live native spectrum, and three primary audio effects: **Bass Boost, Clarity, and Surround**.
- **Ambience** and **Dynamic Boost** are one click away under *More sound controls*. All five original native DSP actions and values remain wired and functional.
- Engine diagnostics stay out of the way when audio routing is healthy, but reveal automatically for driver, output routing, and connection issues.

## Focused Smart Listening
- Adaptive processing, installed model selection, and the existing real-time BrainScan remain immediately accessible.
- Teaching CYN from recent activity, training controls, AUDONIC settings, headroom, and the optional AI DJ live under the accessible *Advanced AI tools* disclosure.
- No trained models, inference implementation, sound processing algorithms, audio driver, or saved presets were replaced.

## Safety and compatibility
- The same native **FxSound/Cyn.exe** driver and headless host remain in charge. Riff is only the user interface; there is no second DSP audio pipeline or simulated visualizer.
- Presets, device selections, 31/35/39-band equalizer controls, auto updater, and desktop shortcut routing remain available.
- Responsive layout, keyboard focus, and reduced-motion rules were refined. The Quiet UI test suite checks the actual native-control IDs, DSP callbacks, and accessibility disclosures.

Install v2.0.96 over the previous version; no uninstall is needed. Windows build/CI checks do not substitute for on-device audio and appearance verification. Existing AGPL FxSound and MIT Riff attribution remain included.

Windows x64.
