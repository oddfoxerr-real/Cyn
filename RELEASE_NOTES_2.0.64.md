# CYN v2.0.64 — Dark Sound Studio refinement

- Restores CYN's curved navigation spine with a subtle cyan edge.
- Unifies the Sound Studio, equalizer, live spectrum, and effects surfaces with a consistent near-black treatment.
- Simplifies the redundant workspace framing and reduces nested card borders.
- Rebalances the equalizer workspace to make real DSP controls the focus.
- Improves dense 31–39-band EQ label readability without changing the equalizer filters.
- Preserves live AI controls, audio routing, saved presets, and existing customization.

This is a native Windows UI release. No new AI model or audio processing changes are included.
