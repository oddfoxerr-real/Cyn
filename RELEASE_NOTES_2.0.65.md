# CYN v2.0.65 — Black interface and sidebar correction

- Removes the filled Bézier sidebar shape that created a protruding bump into the workspace.
- Restores a straight, consistent sidebar boundary with a small, decorative corner accent.
- Unifies the main shell and native EQ, spectrum, and audio enhancement panel backgrounds around a near-black palette with understated blue highlights.
- Retains real DSP controls, the AI model controls, presets, device routing, and existing customization.
- Updates dark-theme regression assertions to match the corrected geometry and palette.

This release changes native presentation, not the underlying audio processing.
