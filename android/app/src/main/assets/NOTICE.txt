ANDROID AUDIO CLARIFICATION
CYN Android does not bundle the Windows FxSound virtual driver. Android
native library playback uses a mobile PCM DSP path adapted from CYN, while
other apps' audio effects depend on Android session permissions.
No equivalent Windows-driver audio claim is made.

Personal learning and audio features remain on the device. Update checks
contact the project's official GitHub releases endpoints, and authorized
downloads follow the user's chosen automatic-update preference.
