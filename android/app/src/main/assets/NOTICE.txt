This Android APK contains Cyn's own branding, palette values, Java code and the
Cyn synthetic starter parameters under AGPL-3.0-or-later. It uses Android's
platform APIs, fonts and audio effects. No Gilroy fonts, JUCE modules, Microsoft
runtime, Windows drivers, fxdevcon, or DfxSetupDrv are bundled in this APK.

The accompanying Cyn Android source ZIP contains the corresponding source
and build instructions. Gradle wrapper is build tooling under Apache-2.0;
see GRADLE-LICENSE.txt in the source archive. Android SDK and JDK are separate
build tools, not redistributed inside this APK. No warranty is provided.

Android feature extraction differs from the desktop model's training domain.
The bundled model is optional and experimental, with no Android or real-song
accuracy claim. Personal learning trains on this phone. Audio is never recorded
or uploaded. This APK has no Internet permission.
