# Cyn 2.0.5 — Smooth UI Animations

- New **Smooth animations** preference, available in **Settings → Help → Appearance**, the main menu, and system tray.
- Native drop-down/pop-up menus fade into view (190 ms) rather than appearing abruptly.
- Combo box arrows rotate smoothly on open/close.
- More gradual hover and press easing for buttons, sliders, and toggles.
- Popup layout and hit targets remain stationary during animation.
- The setting persists across launches. **Reduce motion** takes priority and disables these animations.
- Keeps the complete set of 19 existing themes and the repaired v2.0.4 GitHub updater.

The update installs in place. Download the Windows x64 installer or use Cyn 2.0.4's **Check for updates** command.
