HOW IT WORKS

From your ears to everyone else's.

01

Teach Cyn

Drag across recent audio in Cyn's Smart listening timeline, select an effect, and label it More or Less.

02

Train and refine

Run Cyn's local neural trainer or retrain from your private learning file here. Only numerical sound features are used.

03

Export and share

Give the model a name. Export its weights, submit a public profile, and collect community reviews on GitHub.

04

Import to Cyn

Download a .cynai.json file and use Smart listening → Import AI. Cyn validates it and saves a backup.
