# Cyn 2.0.3 — Charcoal Desktop Theme

- Adds **Charcoal Desktop**, Cyn's nineteenth native theme, with a layered charcoal palette.
- Palette: main `#181818`, side panels `#191C1E`, raised surfaces `#212121`, borders `#363636`, main text `#E7E7E7`, secondary text `#A5A5A5`.
- Keeps all existing 18 themes and their preference identifiers unchanged.
- Updates the executable and installer version to `2.0.3` to support automatic detection by the GitHub Releases updater in v2.0.2.

**Choose Menu → Theme → Charcoal Desktop** (also available from the tray menu).
