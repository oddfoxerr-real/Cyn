# Cyn modification notice

Cyn is a modified FxSound distribution, not an official FxSound release.
Original copyright notices and licenses are retained.

2026-10-09: Cyn contributors changed the application identity, icons, interface,
theme palettes, animations, local preference learning, audio adaptation, device
handling, local control interfaces, Windows build and installer packaging.
Subsequent commits through `cb05744` added selectable themes, animated menus and
the staged updater. These changes include JUCE popup-menu modifications; JUCE's
own GPL/ISC terms remain applicable to its files.

2026-10-10: Licensing remediation replaces Gilroy font files and their embedded
resource bytes with SIL-OFL Manrope, adds third-party copyright/license copies,
fixes language-font packaging, adds source/license access in the UI and status
response, and records unresolved distribution questions. The charcoal theme's
display name becomes Charcoal Desktop; its saved numeric identity and all colors
are unchanged. Theme counts are omitted from user-facing documentation.

The base revisions and component licenses are listed in THIRD_PARTY_NOTICES.md.
This notice describes modifications, not ownership of upstream components.
