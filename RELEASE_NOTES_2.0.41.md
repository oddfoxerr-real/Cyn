# Cyn v2.0.41 — Dark Theme: black glass and connected web

This update corrects the gray **Gemini Night** appearance. The theme is now simply called **Dark Theme**.

## What changed
- Main workspace: near-black **#050607**. Menus, dropdowns, cards, sidebar and the neural activity panel use near-black glass surfaces instead of charcoal/blue-gray blocks.
- A **real dotted, connected web mesh** and faint cool-white/blue glow spread across the lower workspace, reaching into large panels instead of stopping behind them.
- Faded corner lighting and subtle audio-reactive glow preserve readability. Reduce Motion keeps the pattern still.
- Existing AI-specific live neural colors and meaningful path filtering stay intact, as do the Music/Movie profile controls.

## Backwards compatibility
- Uses the **same final theme slot** previously called Gemini Night. Anyone who had it selected keeps the selection after upgrading.
- Preserves all other 20 themes, saved settings, previously trained AI profiles, Cyn v2.0.39 bass/kick fixes, and the Version/Update buttons introduced in v2.0.40.
- No new model training or DSP changes.

## Verification
Automated theme tests check black RGB values, connected mesh geometry, profile-specific live neural graph wiring and the Windows UI build. As always, visual contrast should also be checked on a real display.

No external Google/Gemini graphics, branding, or assets are used.
