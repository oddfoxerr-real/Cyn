# Cyn v2.0.42 — Pure-black Dark Theme, retained liquid mesh

This is a correction to the v2.0.41 Dark Theme based on the user's screenshots: the **mesh must stay**, but there must be **no gray panels, blue-gray background, or gray glow**.

## What changed
- Main workspace is pure black (`#000000`). Sidebar and large cards use `#000000`–`#010102`; menu, dropdown, button and control surfaces use near-black `#010203`–`#020307` materials.
- Existing connected **dotted mesh/web pattern is retained** behind the content and faintly on larger panels. It fades toward the upper centre rather than being a harsh static grid.
- Slow multi-frequency movement gives the connected nodes an organic flowing look. Reduce Motion freezes it.
- Small blue-white corner glow pools subtly illuminate the mesh. The broad gray/white haze is removed.
- Comboboxes, popup menus and button backgrounds no longer brighten into charcoal/gray in Dark Theme.
- Real profile-dependent neural activity colors and weighted connections are unchanged.

## Preserved
- Previously selected **Dark Theme** stays selected (same saved theme slot).
- All 20 other themes stay intact.
- Trained models, previous audio/bass/kick fixes, user data, Version button and updater are unchanged.

## Validation
Automated checks verify that all surface palette roles are black, that connected liquid mesh links exist, that reduced motion works, and that native Windows and installer builds pass. A final visual review on actual displays is still useful.
