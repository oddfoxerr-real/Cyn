# Cyn Android 0.1.2 preview

Music is now the home screen, with a prominent Enable Cyn button, connection status and sound controls. Local playback is available separately in Files. Learn holds personal training; More holds themes, updates and credits.

Install the APK over your existing Cyn app; do not uninstall. The original signing certificate and application ID are retained, preserving settings and local models. On 0.1.1, use More/Themes > Check for Android updates. Version 0.1.0 needs a manual APK download.

Build and lint pass with no errors; 285 host assertions pass. Physical-phone layout and audio compatibility remain unverified. External-player support depends on Android audio sessions; owning an EQ does not guarantee that a particular player routes through it.

The attached source archive contains the corresponding Android source and build instructions. No private signing material is included.
