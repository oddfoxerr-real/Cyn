# Cyn 2.0.2 — Themes and GitHub updates

- 12 new themes: Sakura, Arctic, Sandstone, Obsidian, Emerald, Deep Sea, Neon Tokyo, Synthwave, Solar Flare, Crimson, Mocha, Monochrome.
- Total 18 native themes with persistent preferences.
- Corrects icons for light palettes.
- Restores the native Check for updates command with a Cyn-specific GitHub Releases checker.
- Enables daily release checks, with user approval before downloading/installing.
- Requires both a versioned installer and SHA-256 asset before offering an update.

## Important first upgrade

Cyn 2.0.1 did not have a functioning updater. Users must manually install 2.0.2 once. Newer releases can then be detected and offered inside Cyn.

## Installer

Publish `Cyn-Setup-2.0.2-x64.exe` and `Cyn-Setup-2.0.2-x64.exe.sha256` to the v2.0.2 GitHub Release.

Desktop compilation/runtime validation is required on Windows.
