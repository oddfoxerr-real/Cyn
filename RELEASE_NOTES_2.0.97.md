# CYN Windows 2.0.97 — Restore original Riff UI

This corrective release undoes the unintended **Quiet UI** layout introduced in CYN v2.0.96. The UI simplification was requested for the separate HALO Android project, not CYN.

## Restored
- Original CYN v2.0.95 Riff renderer layout, navigation, and control presentation.
- Always-accessible native Sound Studio and Smart Listening controls without Quiet UI disclosures.
- Original styling, without the later minimalist graphite CSS override.

## Preserved
- The original native FxSound / Cyn.exe DSP engine and effect mappings.
- Native physical Windows output routing fixes included in v2.0.95.
- EQ, APEX models, AUDONIC options, presets, diagnostics, and updater wiring.
- Existing settings, libraries, and installed audio processing assets.

No data migration or audio algorithm changes are part of this corrective UI release. CYN 2.0.97 advances the version so installations of the already-published 2.0.96 can receive the restored interface through normal update detection.

Windows x64.
